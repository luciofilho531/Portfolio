## Options
Opção A (escolhida): HTML5, CSS3 e JavaScript, hospedados no GitHub Pages. Vantagens: simplicidade, custo zero para repositório público, leveza e fácil manutenção. Limitação: recursos dinâmicos precisam de serviços externos. Opção B: React/Next.js, que oferece componentes reutilizáveis, mas adiciona configuração e build para iniciantes.
