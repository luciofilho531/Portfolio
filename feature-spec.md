# FEAT-001: FEAT-001 - Página inicial do portfólio, com navegação e seções identificáveis.

Status: DRAFT - human review required

## Acceptance criteria
- AC-001: Dado que o visitante acessa o endereço público, quando a página carregar, então deve ver o nome profissional e um resumo de apresentação.
- AC-002: Dado que o visitante clica no menu Projetos, quando a ação ocorrer, então a página deve navegar até a seção correspondente.
- AC-003: Dado que a página é aberta em largura de 390 px, quando o visitante navega, então o conteúdo não deve exigir rolagem horizontal.
- AC-004: Dado que um link GitHub é acionado, quando aberto, então deve direcionar ao perfil correto em nova aba.
- AC-005: Dado que uma imagem informativa é exibida, quando lida por tecnologia assistiva, então deve ter texto alternativo significativo.
